# Asansör Aynasının Narsisizm Denetim Kurulu

> **Resmî uyarı:** Bu depo bir şaka değildir. Asansörde kendinize bakmanız ulusal bir meseledir.

## Kurumun görevi

Asansör kabinindeki ayna, vatandaşın yüzünü göstermek için değil, **narsisizm oranını ölçmek** için asılmıştır. Kuruluş 2026 yılında, bir kişinin 7. katta saçını düzeltirken 2. katı kaçırması üzerine kurulmuştur.

Bu yazılım:

- bakış süresini ölçer
- kaş kaldırma açısını hesaplar
- iç sesinizdeki "hmmm"i tespit eder
- resmi tutanak basar
- cezayı uygular (genelde bir kat fazla inmek)

Aynayı kırmaz. Ego kırılabilir. Garanti yoktur.

## Kurulum

Python 3 yeter. Ayna zorunlu değildir ama yoksa kurul görevini hayali ayna üzerinden yürütür.

```bash
python3 narsisizm_denetimi.py
```

## Örnek çıktı

Program sizden isim ve kat ister, sonra bilimsel (değil) bir tutanak basar. Çalışır. Gerçekten çalışır. Hayatınızı düzeltmez.
